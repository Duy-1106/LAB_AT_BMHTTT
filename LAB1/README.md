Nội dung đã thực hiện
- Thiết lập Kali Linux, Windows Server 2022 và Ubuntu Server.
- Cấu hình SSH Server trên Windows Server.
- Cấu hình Telnet Server trên Ubuntu Server.
- Bắt và phân tích gói tin bằng Wireshark.
- So sánh Telnet và SSH.
Kết quả
- SSH sử dụng mã hóa nên không đọc được username, password và lệnh dưới dạng plaintext.
- Telnet không mã hóa nên có thể quan sát dữ liệu trong TCP Stream.
Lưu ý
- Wireshark được chạy trên Kali Linux.
- SSH sử dụng TCP port 22.
- Telnet sử dụng TCP port 23.
